# HydrationReminder

## About This Project

This project was built during Mobile Application Development Lab 06. It is a Hydration Reminder application developed using React Native and Expo.

The main features covered in this lab include:

- **Tab Navigation:** Implemented a multi-tab layout (Reminder, Tips, About) using `expo-router`.
- **Local Notifications:** Used `expo-notifications` to request OS-level permissions and schedule repeating local device alerts based on a user-defined time interval.
- **Foreground Handling:** Configured global notification handlers to ensure alerts display even when the app is actively open in the foreground.
